
# Machine-Learning Experiments

This folder contains the Google Colab notebooks used
to develop and evaluate the synthetic mission request
classification prototype.

The experiments demonstrate:
- Data loading and inspection
- Training and testing splits
- TF-IDF feature extraction
- Logistic regression classification
- Accuracy, precision, recall, and F1 evaluation
- Confusion matrix visualization
- Illustrative human-review logic

All datasets are synthetic.
This is an educational prototype, not a production system.
